# Global Life Expectancy Analysis

A comprehensive statistical analysis of global life expectancy using longitudinal country-level data.

The project combines classical statistical modeling, multilevel analysis, regularization, predictive modeling, and robust validation to investigate factors associated with life expectancy across countries and over time.

## Key Methods

- Exploratory data analysis and data-quality auditing
- Missing-data analysis and panel-aware imputation
- Multiple linear regression and regression diagnostics
- Multicollinearity and interaction analysis
- AIC/BIC-based model selection
- Ridge, Lasso, and Elastic Net regularization
- Mixed-effects models with random intercepts and slopes
- Temporal effects and longitudinal analysis
- Grouped cross-validation by country
- Temporal train–test validation
- Random Forest and XGBoost
- Permutation importance, partial dependence, and SHAP
- Multiple imputation and sensitivity analysis
